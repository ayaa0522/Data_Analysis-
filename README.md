#E-commerce Data_Analysis-Prpject
Project overview:
This project analyzes an e-commerce sales dataset containing 34,500 transactions between 2023 and 2025.The main goal was to explore customer behavior, identify business problems, discover sales patterns, and generate actionable insights to improve profitability and operational performance.

The project was completed using:
Python
Pandas
Excel
Power BI

The problem:
Despite generating approximately 5.87M in total sales, the business faces lower profitability due to high discount usage, increasing return rates, and uneven regional performance. 
Key issues discovered:
High discounts reducing profit margins.
6% return rate causing revenue loss.
Weak sales performance in the Central region.
High return rates in Fashion and Electronics categories.
